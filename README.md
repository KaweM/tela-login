## 🎯 Objetivo

Praticar a criação e estilização de interfaces, trabalhando com formulários e conceitos básicos de desenvolvimento web.

## 🚀 Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/KaweM/tela-login.git
   ```
2. Abra o arquivo `index.html` no navegador.
